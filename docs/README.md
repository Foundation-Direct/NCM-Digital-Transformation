# ASC Technical Tracking Standards

Welcome to the ASC tracking implementation standard for third-party tools on dealership websites.

This documentation describes:

- How tools should identify themselves on a site
- How integration types (iframe, modal, new window, redirect) affect tracking
- Required `window.dataLayer` event patterns
- GA4/GTM requirements
- Implementation examples
- Vendor attestation requirements

Use the navigation sidebar to jump to specific topics.

> **Audience:** Product Engineering, Analytics, Integrations, and QA teams for third-party vendors and internal measurement platforms.
